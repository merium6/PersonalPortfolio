# Maryam Ali — Portfolio

Premium light-mode personal portfolio built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## Design

- Off-white background (`#F8F9FA`), white bento cells, charcoal text (`#1A1A1A`)
- Asymmetric Neo-Brutalist grid with sharp corners and 1px borders
- Electric indigo (`#4F46E5`) reserved for links, buttons, and hover states

## Run locally

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `src/data/profile.ts` — CV content and links
- `src/components/` — Hero, Experience, Projects, Skills, Education, Contact, Header, Footer, BentoGrid
- `src/app/page.tsx` — page composition
